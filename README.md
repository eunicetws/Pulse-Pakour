# Pulse Parkour  
**Software Engineering – COMP1023 (UNMC)** 

---

## Project Overview

**Pulse Parkour** is a **endless runner game** developed in Java.  

Players must continuously run, jump, and avoid obstacles while surviving as long as possible.  
The game progressively increases in difficulty, testing the player’s reaction speed and timing.

This project was developed as solo in the span of 3 months for **Software Engineering (COMP1023)** course in University of Nottingham Malaysia (UNMC)

## System Requirements

Before running the game, ensure you have:

- **Java 23.0.1** installed   
- IDE (optional) such as IntelliJ IDEA / VS Code / Eclipse  

To verify Java installation:

```bash
java --version
```

---

Run Using an IDE

1. Open the project folder in your preferred IDE.
2. Ensure the project SDK is set to **Java 23.0.1**.
3. Run the main class file.
